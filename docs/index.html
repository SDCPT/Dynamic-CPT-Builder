Why This Plugin is Different

While many CPT plugins offer flexibility, they often fall short on security. Secure & Dynamic CPT Builder is built on the principle of "security by default."

It separates submitted data from the main WordPress post table and uses strict validation, making it an ideal choice for projects where data integrity and user security are critical.

Installation & Usage

Get started with Secure & Dynamic CPT Builder in just a few simple steps

1 Installation 

1. Upload the plugin folder to your `wp-content/plugins/` directory.
2. Activate the plugin through the Plugins → Installed Plugins menu in WordPress.
3. A new admin menu item named "Secure CPTs" will appear.

2 Create a CPT

Go to the "Secure CPTs" admin page and fill in the details:

  • Enter a CPT Key (machine-readable identifier)
  • Enter a Name (human-readable label)
  • Define a URL Slug
  • Define your form fields in the Fields JSON editor

3 Fields JSON Example 

{
    "title": {
        "label": "Listing Title",
        "type": "text",
        "required": true
    },
    "content": {
        "label": "Description",
        "type": "textarea"
    },
    "email": {
        "label": "Contact Email",
        "type": "email",
        "required": true
    },
    "phone": {
        "label": "Phone Number",
        "type": "tel"
    }
}

4 Frontend Display

Display a Form

Place this shortcode on any page or post:

[secure_cpt_form cpt="your_cpt_key"]

Display a List of Entries

Place this shortcode on any page or post:

[secure_cpt_list cpt="your_cpt_key"]

Note: All registered CPTs are also automatically displayed on their standard WordPress archive pages (e.g., /your_cpt_slug/).
